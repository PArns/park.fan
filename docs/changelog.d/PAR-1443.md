### Admin: Mindestversion der App

Unter „App-Version“ im Admin stellen Owner je Plattform (iOS, Android als vorbereitet) die Mindestversion, den Mindest-Build, den Link zum Aktualisieren und die Hinweise pro Sprache ein, die die App zeigt, wenn sie zu alt ist. Ein höheres Minimum fragt nach, und eine Testversion zeigt, was die API antworten würde.
