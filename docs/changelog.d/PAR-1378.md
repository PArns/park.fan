### Tagesplaner: Saisontage tragen den Composer `h5_season`

An einem Tag einer laufenden Parksaison skaliert die API die 15-Minuten-Kurve von `/plan/day` jetzt
mit demselben Saison-Niveau, das der Kalender für den Tag zeigt (API PAR-1378), und meldet das als
Composer `h5_season`. `PlanDayComposer` in `lib/api/types.ts` kennt den Wert; nichts verzweigt
darauf, Planer und Kalender zeigen für denselben Tag dasselbe Niveau.
