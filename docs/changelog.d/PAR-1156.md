### Ein Token erstellen verlangt das Passwort, die Freigabeseite nennt das Alter der Anfrage

`POST /v1/admin/auth/tokens` prüft jetzt das Passwort und, wenn das Konto einen zweiten Faktor hat, den Code. Ein Token überlebt die Sitzung, die es ausstellt, also konnte eine gestohlene Sitzung sich eines ausstellen, das nach ihrem Ende weiter las. Der Dialog unter `/admin/account` hat dafür ein Feld „Passwort“ (`autocomplete="current-password"`) und, wenn `identity.totpEnabled` gesetzt ist, ein Feld „Code“ (`autocomplete="one-time-code"`, ein Feld wie im Login). Die Antworten der API stehen auf Deutsch an dem Feld, das sie meint: `invalid-password`, `invalid-totp` (ein Code gilt nur einmal, auch ein wiederholter scheitert), `totp-required` für eine Sitzung, die vom zweiten Faktor nichts wusste (das Codefeld erscheint dann), die Sperre des Limiters in Minuten, und ein 401 ohne einen dieser Werte als beendete Sitzung. Beide Felder werden nach jeder Anfrage geleert, ob sie gelang oder nicht, die Eingabemarke steht danach im Passwortfeld. `createTokenBody` sendet `totpCode` nur als vollständigen Code, `describeTokenCreateError` ordnet die Antworten zu. Widerrufen verlangt kein Passwort.

Die Freigabeseite unter `/admin/oauth/consent` zeigt aus `createdAt` der Anfrage, wie alt sie ist („vor 2 Minuten gestartet“), und warnt darüber, wenn sie älter als fünf Minuten ist: Wer eine Verbindung gerade in der App startet, landet nach Sekunden hier, eine ältere hat womöglich jemand anderes gestartet und den Link geschickt. Fehlt `createdAt` (eine API, die es noch nicht sendet), steht weder Alter noch Warnung da. Das Alter zählt ab dem späteren von Minutentakt und Abrufzeit der Anfrage, damit ein vorher gelesener Takt es nicht jünger macht.

`OtpInput` (`_ui/controls.tsx`) ersetzt die beiden einzeln gebauten Codefelder der Kontoseite, `lib/admin/totp.ts` hält die Länge und den Ziffernfilter, den auch die Kästchen des Logins nutzen. `Notice` (`_ui/primitives.tsx`) ist der gelbe Hinweiskasten, den das Token-Dialogfenster schon hatte. `formatAgo` in `_lib/format.ts` ersetzt vier Kopien von `formatDistanceToNow(parseISO(…), { addSuffix: true, locale: de })`. `pnpm test:admin-mcp` prüft 66 Fälle (vorher 47), darunter Body, jede Antwort der API und die Grenzen des Alters bei 5 Minuten.
