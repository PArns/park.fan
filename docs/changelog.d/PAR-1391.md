### „Heute bisher" ist im Kalender wieder höchstens eine Stunde alt

Seit PAR-1380 hielt das Kalender-Relay jeden Bereich bei Vercel bis zum nächsten Ring, also auch den
aktuellen Monat und den Einzeltag der Heute-Ansicht. Der Wert „Heute bisher" (`todayCrowdLevel`)
ändert sich aber im Lauf des Tages, ohne dass ein Ring kommt, und blieb so stundenlang stehen. Parkys
Tipp für heute, der eine halbe Stunde frisch ist, wurde daneben als Abweichung ausgeblendet. Ein
Bereich mit einem Tag, den die API als `isToday` markiert, geht jetzt mit `CALENDAR_TODAY_WINDOW`
raus: eine halbe Stunde bei Vercel, eine halbe Stunde bei Cloudflare. Alle anderen Monate behalten
`FORECAST_WINDOW`. Die Regel in `next.config.ts` trägt das kürzere Fenster, `pnpm test:edge-windows`
prüft beide Hälften ([CDN-Caching](../architecture/cdn-caching.md#routes-the-backend-rings)).
