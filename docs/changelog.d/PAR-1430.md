### Parky im Admin: gemeldete Antworten

Meldet jemand in der App eine Antwort von Parky („Antwort melden"), steht das jetzt im Admin an der
Antwort: ein Chip „gemeldet" mit dem Grund (falsch, unangemessen, anderes) und darunter die Notiz,
als reiner Text. Die Chat-Liste unter `/admin/assistant/conversations` markiert solche Chats und
hat den Filter „Gemeldet". Eine Meldung bleibt so lange wie ihr Chat, höchstens 7 Tage.
