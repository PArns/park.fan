### `check:media-urls` wird rot, wenn es nichts geprüft hat

`scripts/check-media-urls.mjs` meldete ohne laufenden Server „0 media URLs across 11 pages“ und vier grüne Haken, obwohl mit Server 3.517 URLs geprüft werden. Jetzt fängt es Abruffehler je Seite ab, zählt die geladenen Seiten und endet mit Exit-Code 1, wenn keine Seite geladen wurde oder keine Medien-URL gefunden wurde. Die Meldung nennt `CHECK_BASE` und `pnpm start`. Zusätzliche Seiten kommen über Argumente oder `CHECK_PAGES` (kommagetrennt), damit ein neuer Beitrag seine eigenen Seiten mitprüft. Die Zusammenfassung nennt `n von m Seiten`.
