### `CLAUDE.md` ist ein Wegweiser, `docs/README.md` führt jede Seite, und die Doku stimmt mit dem Code überein

`CLAUDE.md` hatte 39 KB und wurde in jeder Session ganz gelesen; jede Regel stand dort und in
`docs/rules/README.md`. Jetzt sind es rund 5 KB: was das Repo ist, wo eine Aufgabe anfängt, was für
jede Änderung gilt. Die Regeln stehen nur noch in `docs/rules/README.md`, jede in einer Zeile, neu
dazu `a-renamed-route-keeps-its-old-url`. `docs/README.md` führt jede Seite mit einer Zeile.

Jede Seite ist gegen den Code geprüft und gekürzt, Wiederholungen sind Links. Aufgeteilt:
`docs/blog.md` in `docs/writing/` (ein Kapitel pro Datei, die §-Nummern bleiben),
`trip-planner.md` in `docs/features/trip-planner/`, `design-system.md` in sechs Seiten unter
`docs/design/`, `caching-strategy.md` um `cdn-caching.md`. Erledigte Pläne, Specs und das
SEO-Roadmap-Papier sind gelöscht. `docs/api/` beschreibt nur noch die Frontend-Seite und verlinkt
die Verträge im Backend. `todo.md` und die Backend-Wunschliste sind aufgelöst: Offenes steht in
Linear (unter anderem PAR-1101, PAR-1103, PAR-1106 und PAR-1107). Das README sagt, was die
Seite kann und wie man sie startet.
