### Footer: Der Link zum Entwicklerportal heißt jetzt so

Seit PAR-1366 führt der Link in der Markenspalte des Footers (`components/layout/footer.tsx`) auf
`/developers`, das Entwicklerportal, trug aber noch das Label aus der Zeit, als er auf die Swagger-UI
zeigte: „API Dokumentation“. Wer das Portal suchte, fand es darunter nicht. Der Schlüssel heißt jetzt
`footer.developerPortal` und lautet in den sechs Sprachen „Entwicklerportal“, „Developer portal“,
„Ontwikkelaarsportaal“, „Portail développeurs“, „Portal para desarrolladores“ und „Portale per
sviluppatori“, so wie das Impressum das Portal schon nennt.
