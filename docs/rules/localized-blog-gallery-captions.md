# Localized blog gallery captions

One standing rule. It is indexed from the repo's [`CLAUDE.md`](../../CLAUDE.md), which carries the rule in one line and links here for the reasoning, the measurements and the counter-examples.

a gallery is a **collection** in the media database, and its captions live per image in the sidecar (`alt`/`caption` as `{de,en,nl,fr,es,it}`) — the old `captions.json` + five `captions.<locale>.json` files per folder are gone. A post may still override a caption inline; the same photo legitimately reads differently in two articles. See [public/media/README.md](public/media/README.md).
