# three.js animations (REQUIREMENT)

One standing rule. It is indexed from the repo's [`CLAUDE.md`](../../CLAUDE.md), which carries the rule in one line and links here for the reasoning, the measurements and the counter-examples.

research the real-world reference **first**, then implement; and **verify every animation from all camera perspectives** (coaster player: Front, Follow, Onboard) across the whole timeline and both day/night themes via the headless render harness (`node scripts/render-coaster-elements.mjs`) before shipping — a green build is not enough. See [conventions](docs/development/conventions.md#12-threejs-animations-research-first-then-verify-from-every-perspective-requirement).
