# A wait time is never typed into a post (REQUIREMENT)

One standing rule. It is indexed from the repo's [`CLAUDE.md`](../../CLAUDE.md), which carries the rule in one line and links here for the reasoning, the measurements and the counter-examples.

four articles carried **22 hand-maintained tables across six languages** — a park's top ten, rides compared across parks, weekdays, and Europa-Parks 8 × 10 hour matrix, eighty numbers per locale. They had already drifted with nothing to detect it: the Efteling post said 34 minutes for Joris en de Draak while the park page said 35, and two tables in one Toverland post disagreed by a minute because they were typed a week apart. Every such table is now a fence — `ride-waits-widget` (`park=`+`top=` for a ranking, or a semicolon-separated `rides=` list across parks; **semicolons because a build type holds a comma**) and `hourly-profile-widget`. What stays in the post is what does not move: a coaster's `|Label` and `|Type` are stable facts, the minutes never are. The split between the two modes is about what the table claims — `park` mode is ranked by the data because **the ranking is the claim**, `rides` mode keeps the author's order because the sentence under it depends on that order, and only `rides` mode applies a 60-day floor, because setting two numbers side by side invites subtracting them while a ranking has a `days` column that states each row's basis. And **a sentence next to a widget must not name a figure the widget renders** — write the shape ("gut eine halbe Stunde", "ab Mittag etwa die Hälfte"), which stays true while the number moves. Fetching is centralised in `useParkStatsQueries` (query key, stale window, `useLoadLast` gate) so two tables about one park share a request; `topN` is a **closed set** at the proxy because it lands in the CDN cache key. The hourly table needed a backend projection first: `/stats/hourly` answers eight rides in ~2 KB where the attraction endpoint costs 425 KB, 45 % of it a `schedule` nobody renders. See [blog widgets](content/blog/README.md#6-live-widgets-code-fences) and [API budget](docs/architecture/api-budget.md#blog-widgets-what-a-post-may-fetch).
